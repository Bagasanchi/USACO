# USACO

C++ solutions to [USACO](https://usaco.org/) practice problems.

## Solutions

| File | Problem |
| --- | --- |
| [BasketballOneOnOne.cpp](BasketballOneOnOne.cpp) | Basketball 1-on-1 |
| [Speeding_Ticket.cpp](Speeding_Ticket.cpp) | Speeding Ticket |
| [Teleportation.cpp](Teleportation.cpp) | Teleportation |
| [WeirdAlgorithm.cpp](WeirdAlgorithm.cpp) | Weird Algorithm |

## Running

Each file is a standalone solution. Compile and run with:

```bash
g++ -O2 -o solution SolutionFile.cpp
./solution
```

Some problems read from and write to `.in`/`.out` files via `freopen`, matching USACO's file I/O format.
